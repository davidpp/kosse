## Deviations and decisions

- **Specificity rule.** The design did not say how a `cwd`-only entry and a `process` entry interact; under the existing rule a workerd child under both would be ambiguous. Among the entries matching a process, those naming its `process` take it from those that do not; equally specific entries stay ambiguous. Documented in project-metadata and the matching rules agents read.
- **Bundle budget.** main left 0.16 kB of the 50 kB budget. After dropping the modulepreload polyfill (0.29 kB, unused with one chunk) and trimming copy, S21's dashboard surface still costs about 1.25 kB, so the bundle is 50.80 kB. Commit `build(web): raise the bundle budget to 51 kB for S21` is separate so the owner can decide; without it `check` fails on the budget. Even without the Customize editor (about 0.3 kB) the row and Inspect alone exceed 50 kB.
- **Customize client checks.** Port and probe-path syntax of endpoint rows are left to the server's validator (its message names `services.<id>.endpoints.<port>`); the dialog checks only duplicate ports, which a JSON object would silently merge.
- **Fixture world.** Two fixtures named `vite` now coexist; the copy step used to overwrite the running executable (macOS then kills it), so copies are made with `COPYFILE_EXCL` and reused, and `scripts/window-test.ts` keys rows by the first fixture of a name.
