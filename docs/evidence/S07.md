## Decisions

- **Noise** (hidden until "All listeners"): listeners with no project (system daemons, apps, other users' processes whose cwd is unreadable) and any endpoint the scanner marks `otherUser`. Search still counts hidden matches and offers "Show all listeners".
- **Markers per endpoint**, not per row: HTTP results are per port, so one process with a 200 and a refused port shows both truthfully. Ended and configured rows carry their marker on the name.
- **Stop confirmation is frozen** when it opens (instance, identity, ports, names); a newer snapshot or a restarted server makes Kossé answer `stale`, shown as "Nothing was sent". A deep link to a non-running identity says so in the dialog. Each step moves focus to its safe button.
- **Ended rows** derive from consecutive snapshots in the Query cache entry, by scan clock, not by a page timer. Nothing ticks: staleness flips with one timeout at `scannedAtMs + 2 × interval + 1 s`; the force offer expires with one timeout.
- **Links:** `safeLink` (URL parse, `http:`/`https:` only, no credentials, non-empty host) is the only path to an `href`; the host is always rendered. Declared links are tagged "declared, local" or "declared, not verified".
- **Customize** edits only fields the central profile sets; values from `kosse.json` are shown as hints. Client checks (ID, port, probe path, link URL) run before the server's validation; server refusals (`422 invalidProfile` etc.) are shown verbatim as "Not saved: …".
- **"All listeners" is not persisted.** Product lists UI preferences in the config; that needs a preferences API in `crates/app`, deferred to avoid touching `crates/app` during S08 (recorded in blueprint/architecture.md).
- **Redact features off:** suspense, lazy, memo, portal, view transitions, class components and forwardRef (verified unused by the app, TanStack Query and Lucide; Lucide's `forwardRef` wrapper still renders, no refs are passed). Saved 2.8 kB gzip and brought the bundle under budget; `.oxlintrc.json` forbids importing them.
- **Derived colours mix in OKLab**: an OKLCH `color-mix` with the achromatic surface interpolated hue in WebKit and turned the teal row wash pink (seen in the first WebKit run).
- **Favicon** is referenced from `brand/` in `index.html`; Vite emits hashed copies into the embedded bundle (no duplicate source files).
- **E2E is a separate command** (`bun run test:e2e`), not in `check`: it needs browsers and runs about a minute. CI runs it in the macOS job after `check`.
- **Customize round-trips the central profile.** The form starts from what the snapshot shows the central profile setting (per-field `sources`) and saves those fields back: `disabled` (editable as "Turn this service off"), an explicit empty `links: []`, link `kind`s. kosse.json entries can be overridden by ID. `$schema` is not in the snapshot, so `crates/core` now keeps it from the replaced profile (`ProjectProfile::keep_unknown_from`, test `unknown_fields_are_kept_on_rewrite`). "Remove saved profile" asks for confirmation.
- **Ordering across instances:** another instance's snapshot replaces the cached one only when its scanner's last attempt is no earlier, so a late event from a stopped instance cannot replace its successor. The initial GET reads the cache after it resolves (unit test for the GET-vs-SSE race).
- **Stop in flight:** while a signal is being sent and observed the dialog has no Cancel, its close button is disabled and Escape is refused (`cancel` prevented); the result always lands in the dialog.
- **Rate limits** show Kossé's own message ("A stop was requested less than a second ago" / "Another stop is still being observed"), so the two limits read differently.
- **Markers** differ by shape for every state (filled dot, dot in a ring, open ring, dashed ring, bar, half-filled ring, alert icon); table in web/DESIGN.md.
- **Fixture options for screenshots** (`crates/fixtures`): `--title`, `--port` once per group, and `KOSSE_FIXTURE_ARGS` (a JSON array of options) so the observed command line is only what the driver chose; the default escaping-test title stays for the functional suite. The screenshot world pins 5173, 3000/3001, 4321, 3002, 5432 and 8443 when free (ephemeral otherwise), keeps one process busy and runs the worker unsupervised (it is probed: "not HTTP").
- **Lucide icons** stay as imports (9 icons); inlining them was not measured. Budget headroom is 1.44 kB.
- **Impeccable:** context loaded, owner answers applied (pinned layout, so no concept roll), surface brief in `web/.impeccable/surfaces/`, craft floor followed, detector run (one advisory, fixed), one batched screenshot round and one fix round. The shipped finish-reviewer and documenter agents are not available in this harness; the surface brief's finish contract was met by the orchestrator's two review lenses and the fix round recorded here, and DESIGN.md was written by hand from the built UI.

## Safety

- The suite signals only processes it spawned, through their Node child handles (never by name or bare PID), and Kossé can only signal fixtures listed in `--act-only`. Nothing real is probed (`--probe-only`).
- Real listeners of the machine are visible to the server (it scans everything) but are never probed or signalled; tests locate cards by their temporary root, not by name. Screenshots go through `support/fixture-view.ts`, which removes every service the suite did not start, so no real process name or path can be in a committed image. Worlds live under `/tmp` to keep per-user temp paths out of images.
