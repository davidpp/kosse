## Defects found

- **Probe tests fail while a Kossé of the developer's runs.** The fixtures count every request; a real Kossé probes the tests' temporary projects like any other project of the user. Fixed in docs only: CONTRIBUTING's prerequisites now say to quit any Kossé before `bun run test`/`check`. A code fix (telling the test server's requests apart from another instance's, or putting fixtures where a real instance does not probe) is a design choice left to the owner. CI is unaffected.

No product defect was found: every matrix check passed from the installed binary.
