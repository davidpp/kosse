# Kibernetyk Mono

`KibernetykMono-SemiBold.ttf` is the unchanged SemiBold static font from Kibernetyk Mono **v1.0.1** (OpenType version 1.001), designed by Pavlo Kilko / The Kibernetyk Mono Project Authors.

- Source: [PavloKilko/KibernetykMono](https://github.com/PavloKilko/KibernetykMono)
- License: [SIL Open Font License 1.1](OFL.txt)
- SHA-256: `ca3ac4575a8c2932708b7117c0cde502c23c980e37ad97585a0ffa32f4567cad`

Used for the Kossé wordmark and bundled for native rendering of that wordmark. The logo preserves the font's monospace advances and OpenType shaping: the font decomposes `é` into `e` and its positioned acute accent. A renderer must support shaping; direct glyph lookup produces an empty precomposed `é`. The internal family name is `Kibernetyk Mono SemiBold`. Other interface text has a separate typography policy; this file does not imply that every label is monospace.

Keep `OFL.txt` and its copyright notice with redistributed font files. No font installation or network request is required at runtime. The asset generator outlines the wordmark from this exact local file.
